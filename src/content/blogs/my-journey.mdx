# My Journey as a Full-Stack Developer

Hello! I'm **ANUJ RAJPUT**, a Full-Stack Developer interested in building modern, responsive and user-friendly web applications.

My learning journey has involved working with frontend development, backend services, APIs, databases and developer tools. Instead of focusing only on one part of an application, I enjoy understanding how different parts of a system work together.

## What I Work With

My development work includes technologies from the JavaScript ecosystem such as:

- **React**
- **Next.js**
- **TypeScript**
- **JavaScript**
- **Node.js**
- **Express.js**
- **MongoDB**
- **Git & GitHub**

I continue to learn and improve my skills by building projects and experimenting with different technologies.

## Projects I've Built

### Rentifyy

**Rentifyy** is a product rental platform designed around products such as furniture, cars, bikes, ACs, TVs, refrigerators and similar items.

The project helped me work with frontend interfaces, backend APIs, product-related workflows and database-driven application development.

### Collab Platform

**Collab Platform** is an influencer and brand collaboration platform.

It includes features around campaigns, influencer applications, authentication, user roles, communication, reviews and a payment workflow.

Building this project helped me understand how multiple user roles and different application workflows can work together in a full-stack application.

## What I'm Learning

I believe the best way to improve as a developer is to keep building.

With every project, I try to understand the problem first, build a practical solution, and then improve the code, structure and user experience.

My goal is to continue developing stronger full-stack skills and build applications that are useful, reliable and easy to use.

## What's Next?

I'll use this blog to share my development journey, project experiences, technical concepts I've learned, and solutions to problems I encounter while building applications.
